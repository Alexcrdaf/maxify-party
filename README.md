# 🎬 SyncWave — Платформа для совместного синхронного просмотра видео (P2P Watch Party)

**SyncWave** — современное веб-приложение для совместного просмотра фильмов, сериалов и видео в реальном времени с поддержкой голосового чата и демонстрации экрана.

Проект разработан с учётом работы на **GitHub Pages** (полностью статический хостинг без необходимости развёртывания собственного Node.js/WebSocket бэкенда).

---

## ✨ Ключевые возможности

1. **Режим прямого воспроизведения HTML5 (MP4 / WebM / OGG)**:
   * Мгновенная синхронизация Play / Pause / Seek / Rate.
   * Ведущий (Host) управляет таймлайном для всей комнаты.
   * Защита от бесконечных циклов синхронизации (дебаунсинг и порог рассинхрона 1.5 сек).

2. **Режим «Трансляция вкладки со звуком»**:
   * Использование нативного API `navigator.mediaDevices.getDisplayMedia()`.
   * Передача оригинального видеопотока и системного звука вкладки через WebRTC P2P без программного перекодирования.
   * Автоматическое распознавание завершения демонстрации.

3. **Анализ медиа-источников и обработка DRM**:
   * Распознавание прямых ссылок, YouTube и платных стримингов (Netflix, Кинопоиск, Иви и др.).
   * Информирование пользователей об ограничениях DRM (Widevine, HDCP) и CSP с подсказками по переключению в режим демонстрации вкладки.

4. **Система комнат и ролей**:
   * Генерация понятных 6-значных кодов комнат (например, `K7MX42`), исключающих неоднозначные символы (`0/O`, `1/I`).
   * Подключение по коду или по прямой ссылке `?room=K7MX42`.
   * Управление участниками: передача роли ведущего (Host transfer) и удаление (Kick).

5. **Встроенный голосовой чат (WebRTC Audio)**:
   * Определение активности голоса (VAD) через Web Audio API в реальном времени.
   * Раздельные аудиопотоки: звук медиафайла/вкладки не смешивается с микрофоном для предотвращения эха.

6. **Текстовый чат комнаты**:
   * Быстрый обмен сообщениями во время просмотра с системными уведомлениями о входе/выходе.

## 🏗️ Архитектура для GitHub Pages

* **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons.
* **WebRTC Сигнализация и P2P-соединения**:
  * Реализовано поверх распределённой P2P-сети через PeerJS (облачный сигнальный брокер).
  * Для обхода NAT используются публичные STUN-серверы Google и Cloudflare.
  * Все данные синхронизации (play, pause, seek, chat, host commands) передаются напрямую через **WebRTC DataChannel** между пирами без посредников.
* **Безопасность**:
  * В клиентском коде отсутствуют приватные API-ключи.
  * Все настройки вынесены в переменные окружения и `src/config/index.ts`.

## 🚀 Быстрый старт

### Требования
* Node.js 18+ (рекомендуется 20+)
* npm 9+

### Локальный запуск

```bash
# 1. Клонирование репозитория
git clone https://github.com/USERNAME/syncwave.git
cd syncwave

# 2. Установка зависимостей
npm install

# 3. Запуск dev-сервера
npm run dev
```

Откройте в браузере `http://localhost:5173`.

### Запуск тестов

```bash
npm test
```

### Сборка проекта

```bash
npm run build
```

Собранные статические файлы будут находиться в директории `dist/`.

## 🌐 Публикация на GitHub Pages

Проект полностью настроен для автоматической публикации:

1. Создайте репозиторий на GitHub и отправьте в него код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of SyncWave"
   git remote add origin https://github.com/USERNAME/syncwave.git
   git push -u origin main
   ```
2. Перейдите в **Settings → Pages** вашего GitHub-репозитория.
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
4. Workflow в `.github/workflows/deploy.yml` автоматически соберёт проект и опубликует его по адресу:
   `https://USERNAME.github.io/syncwave/`.

## ⚙️ Переменные окружения (`.env`)

Создайте файл `.env` на основе `.env.example`, если хотите переопределить параметры по умолчанию:

```env
# Максимальное число участников в комнате
VITE_MAX_PARTICIPANTS=10

# Опциональный собственный сигнальный сервер PeerJS
# VITE_PEERJS_HOST=peer.example.com
# VITE_PEERJS_PORT=443
# VITE_PEERJS_PATH=/
# VITE_PEERJS_SECURE=true
```

## 📋 Особенности платформ и DRM

* **Прямые ссылки MP4/WebM**: работают синхронно у всех участников.
* **YouTube**: поддерживается переход и просмотр.
* **Платные сервисы (Netflix, Кинопоиск, Prime Video и др.)**: защищены аппаратным DRM. При попытке прямого захвата браузер может выдавать чёрный экран из-за аппаратного ускорения видеокарты. В интерфейсе предусмотрены соответствующие предупреждения и инструкции.
